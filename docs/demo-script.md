# Demo script (2.5 to 3 minutes)

Recorded during the live session (`docs/live-session.md`), with the live camera and the real SDK. One caption or voice-over line per shot. Target length about 2:50.

## Rules for the recording

- **Live data only.** No `PREPPULSE_REPLAY`, no simulated sessions, and no "SIMULATED DATA" banner or "(simulated data)" label anywhere in the video. Before recording, open Settings in the normal app: if "Past practice tests" lists anything simulated, use "Delete all my data" first, then calibrate fresh.
- **Never press "Start now anyway".** Calibrate right before the test, so the camera is warm and the test starts at once.
- **Words:** describe what was measured, compared with your own baseline. No stress, anxiety, panic, nervous, good/bad, better/worse, normal, or any medical claim, in captions or voice-over.
- **Progress section:** it only shows charts from 3 real practice tests. With one live test it shows "Take 3 practice tests to see your patterns." Either show that line as it is (honest, recommended), or take two more quick tests in the same session first (each uses SDK credits).
- **Order:** record "Delete all my data" last, after any screenshots for the README and the PDF, because it removes the session.
- Screen recording at 1080p or higher; keep the mouse slow over the report.

## Checks after recording

- Scrub the whole video once for any "SIMULATED DATA" banner, "(simulated data)" label, the API key, a terminal showing `.env`, or other people or personal details in the camera preview.
- Captions match the app's wording (the report title is "Your pressure map", subtitle "How your body responded, question by question").
